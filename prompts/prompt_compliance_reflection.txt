EAGLE Prompt Compliance Reflection stage.

Audit the two active prompt genes only. This stage does not evaluate wins,
losses, strategy strength, Java quality, or match behavior. Its only task is to
find statements that cannot be implemented legally and faithfully in the
supplied MicroRTS world.

For strategy_prompt, flag only rules that use nonexistent game concepts,
conditions unavailable from observable state, illegal actions or production
relations, or ambiguous/conflicting instructions that prevent an executable
interpretation. A strategy may be aggressive, defensive, economic, mixed, or
otherwise unconventional; strategic type is not a compliance violation.

For code_generation_prompt, flag only policy-specific instructions, unsupported
API assumptions, requests to modify the immutable scaffold, or ambiguous and
conflicting translation rules. It must remain a reusable policy-to-Java gene,
not a second game-playing policy. Use Current reusable rules to identify the
effective canonical rule set; a legacy free-form prompt may have no retained
rules.

Do not output a rewritten prompt, Java, a patch, match analysis, or performance
advice. State correction goals in general terms and do not invent requirements
beyond the supplied contracts.
