IMMUTABLE MICRORTS ACTION AND JAVA API CONTRACT.
This contract overrides every conflicting reusable policy-to-Java instruction.
Do not edit any source outside EAGLE_AGENT_STRATEGY_START/END. Do not redefine,
remove, rename, or bypass the fixed helpers. Strategy code may add private helper
methods only inside the strategy region.

Issue actions only through these fixed helpers:
- commandMove(Unit unit, int x, int y)
- commandHarvest(Unit worker, Unit resource, Unit base)
- commandTrain(Unit producer, UnitType unitType)
- commandBuild(Unit worker, UnitType buildingType, int x, int y)
- commandAttack(Unit attacker, Unit target)
- commandIdle(Unit unit)

Use these fixed lookup helpers instead of inventing engine queries:
- isIdleAlly(Unit unit, AgentContext context)
- nearestEnemy(Unit source, AgentContext context)
- nearestResource(Unit source, AgentContext context)
- ownBase(AgentContext context)

AgentContext exposes only context.player, context.gs, and context.units. The
following MicroRTS reads are allowlisted; do not call any unlisted method or
field on GameState, PhysicalGameState, Player, Unit, UnitType, or PathFinding:
- GameState: getTime(), getPlayer(int), getUnits(), getUnitAction(Unit),
  getPhysicalGameState(), and free(int, int).
- PhysicalGameState: getWidth(), getHeight(), getTerrain(int, int), and
  getUnit(long).
- Player: getResources().
- Unit: getPlayer(), getType(), getX(), getY(), getID(), getResources(),
  getHitPoints(), and getMaxHitPoints().
- UnitType public fields: cost, hp, canAttack, canHarvest, isResource,
  isStockpile, and attackRange.
- Known UnitType variables: resourceType, workerType, lightType, heavyType,
  rangedType, baseType, and barracksType.

Exact corrections for common invalid APIs:
- Use context.gs.getTime(), never getTick() or getTickCount().
- Use unit.getID(), never getId().
- Use getHitPoints()/getMaxHitPoints(), never getHealth()/getMaxHealth().
- Use unit.getResources(), never resource-carrier or carrying helper methods.
- Use context.gs.getPhysicalGameState().getWidth()/getHeight(), never map,
  map-width, map-height, spawn-location, tile, or base methods on GameState or Player.
- Use context.gs.getUnitAction(unit), never unit.getAction() or unit.getTask().
- context.units is a List<Unit>, never a map; count/filter it with loops.
- Every added helper that reads player, state, or units must accept AgentContext;
  never reference a context variable that is not a parameter or local variable.
- Represent coordinate pairs as int[][], not an int[] containing nested pairs.
- Never construct synthetic Unit, GameState, AgentContext, PathFinding, or
  PathChoice objects to query engine state.
