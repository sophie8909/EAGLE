# Meeting 0830 PowerPoint 模板

主要參考為 Meeting 目錄的五張 `20260830_eagle_*.png`。

## 檔案與使用

- `deliverables/Meeting_0830_Template.potx`：PowerPoint 模板，開啟後建立新簡報。
- `deliverables/Meeting_0830_Template.pptx`：可直接開啟、複製頁面及編輯的範例簡報。

包含八種原生版面配置：封面、章節、三欄比較、八步流程、結構關係、實驗結果、結論與後續、設計原則。可在 PowerPoint 的「新增投影片／版面配置」選取。方括號內容為可替換文字，沒有填入虛構的實驗數據。

文字為原生可編輯佔位符。卡片框線、編號底色與箭頭位於版面配置，可在「檢視／投影片母片」調整。四角植物邊飾裁切自原參考圖，保留為圖片。

## 視覺原則

沿用暖白底、深酒紅標題、玫瑰色細框與植物邊飾。金色用於關鍵差異、目前方案或主要發現。比較欄位使用一致順序；流程以編號與方向引導閱讀。保留原圖 1672 × 941 的畫布比例。

參考來源為 PNG，無法取得原字型資訊；以本機可用的 PMingLiU（新細明體）近似重建襯線字體。另一台電腦若未安裝此字型，PowerPoint 可能替換字型。
